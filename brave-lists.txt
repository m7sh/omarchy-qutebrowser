# ==============================================================================
# Brave filter-list catalog for qutebrowser
# ==============================================================================
# Mirrors the default-enabled entries of Brave's own catalog:
#   https://github.com/brave/adblock-resources/blob/master/filter_lists/list_catalog.json
#
# One URL per line. Lines starting with '#' are ignored, so you can disable a
# list by commenting it out. After editing, run `:adblock-update` in qutebrowser
# (or press `ta`) to rebuild the engine cache.
#
# Brave's desktop defaults: "Brave Default Adblock Filters", "Brave Default
# Privacy Filters", "Brave First Party Adblock Filters" and the cookie-notice
# blocker. Android-only and mobile-notification lists are intentionally omitted.
# ==============================================================================
